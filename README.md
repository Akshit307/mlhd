## Run

**Option A: Jupyter (recommended for the demo):**
```bash
jupyter notebook SIT307_HD_Heart_Stacking.ipynb
# Kernel → Restart & Run All
```

**Option B: headless:**
```bash
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=7200 SIT307_HD_Heart_Stacking.ipynb
python make_report.py        # optional: rebuild the PDF report from the new results
```

Runtime is about 25 minutes on a laptop CPU. Most of that is the 50-fold cross-validation in Part 2. All randomness is seeded (`SEED = 42`), so the numbers match the report. The only exception is the 3rd or 4th decimal of some test statistics, where multi-threaded tree ensembles introduce floating-point noise.

## Method in one paragraph

**LACS (Leakage-Aware, Clinically-encoded, Convex Stacking):** (1) de-duplicate to patient level and evaluate with 10×5 repeated stratified CV on identical folds for every model; (2) map the undocumented codes `ca = 4` and `thal = 0` back to missing, impute inside the training fold, and one-hot encode the nominal features `cp`, `restecg`, `slope`, `thal`; (3) train seven regularised, diverse base learners (LR with inner-CV-tuned C, RBF-SVM, KNN, NB, RF, Extra-Trees, shallow XGBoost); (4) combine their out-of-fold probabilities with non-negative weights that sum to 1 (fit by minimising log-loss), shrunk 50% toward the uniform average.
